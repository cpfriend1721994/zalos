Zalo trên Linux
Nhẹ, Mượt, Nhiều Tính Năng Hơn

Zalos là ứng dụng Zalo cho Linux: nhẹ bộ nhớ, khởi động nhanh, chạy tự nhiên trên cả Wayland và X11 — và bổ sung hàng loạt tính năng mà bản Zalo thông thường không có: khóa ứng dụng bằng mã, chống nhìn trộm, thư mục nhãn, hẹn giờ gửi tin và nhiều hơn nữa.

⏰

Soạn trước và hẹn giờ gửi tin, lưu sẵn các mẫu tin nhắn nhanh để gửi lại chỉ trong vài giây.

🤫

Rời nhóm trong im lặng

Rời khỏi nhóm mà không gửi thông báo cho các thành viên khác — kín đáo và lịch sự.

Tải & Cài Đặt

Chọn định dạng phù hợp với bản phân phối Linux của bạn.

Mỗi bản phát hành có file riêng cho x86_64 và ARM64 (aarch64) ở mọi định dạng — hãy chọn đúng kiến trúc máy của bạn.
Không chắc? Chạy uname -m trong terminal: x86_64 hoặc aarch64.
⬇️ Mở trang tải bản mới nhất

Tải file AppImage đúng kiến trúc (x86_64 hoặc aarch64), cấp quyền chạy và dùng ngay trên hầu hết các bản phân phối:

# x86_64
chmod +x Zalos-1.0.4-x86_64.AppImage
./Zalos-1.0.4-x86_64.AppImage

# ARM64
chmod +x Zalos-1.0.4-aarch64.AppImage
./Zalos-1.0.4-aarch64.AppImage

Dành cho Ubuntu 24.04+ và các bản dựa trên nó (tải gói amd64 hoặc arm64):

sudo apt install ./zalos_1.0.4-1~ubuntu24.04_amd64.deb
# hoặc
sudo apt install ./zalos_1.0.4-1~ubuntu24.04_arm64.deb

Dành cho Fedora 43+ (tải gói x86_64 hoặc aarch64):

sudo dnf install ./zalos-1.0.4-1.fc43.x86_64.rpm
# hoặc
sudo dnf install ./zalos-1.0.4-1.fc43.aarch64.rpm

Chạy thử không cài, hoặc cài vào user profile:

nix run github:cpfriend1721994/zalos
nix profile install github:cpfriend1721994/zalos
