Trải nghiệm Zalo Native
Siêu Nhẹ, Mượt Mà, Chuẩn Linux

Nói lời tạm biệt với ứng dụng Electron ngốn hàng gigabyte RAM. Zalos được viết lại hoàn toàn bằng Qt6 & C++, tương thích 100% với giao diện GTK (GNOME) lẫn Qt (KDE), chạy Native trên cả Wayland và Xorg.

Tính Năng Nổi Bật

Được tối ưu riêng cho hệ sinh thái máy trạm Linux hiện đại.

🖥️

Hỗ Trợ Native Wayland & Xorg

Sử dụng QPA wayland;xcb tự động nhận diện compositor. Tích hợp thanh tiêu đề CSD kéo thả mượt mà, không bao giờ mất nút điều khiển trên GNOME Wayland.

🎨

Hòa Nhập Theme GTK & Qt

Tự động đồng bộ chế độ Sáng / Tối thông qua D-Bus Portal và GNOME Settings. Sử dụng hộp thoại mở file chuẩn của GTK/GNOME và Breeze của KDE Plasma.

🔒

Mã Hóa Đầu Cuối (E2EE) C++

Mô-đun db-cross-v4 viết bằng C++ thuần túy, dùng OpenSSL AES-256-CBC và LZMA để giải mã tin nhắn E2EE và cơ sở dữ liệu SQLite offline an toàn tuyệt đối.

🔔

Khay Hệ Thống & Badge Đếm

Tích hợp StatusNotifierItem vẽ trực tiếp số lượng tin nhắn chưa đọc lên icon khay hệ thống, không cần cài thêm extension phức tạp.

📞

Cuộc Gọi PipeWire & Opus

Kế thừa giao thức tín hiệu zcall-native (ZRTP/SRTP), xử lý luồng âm thanh Opus và chia sẻ màn hình qua PipeWire portal hiện đại.

📦

Đóng Gói Đa Nền Tảng Chuẩn

Hỗ trợ đầy đủ AppImage (chạy ngay), RPM (Fedora, openSUSE), NixOS (reproducible Flakes) và Flatpak được build tự động qua Docker container.

Hướng Dẫn Cài Đặt

Chọn định dạng cài đặt phù hợp với bản phân phối Linux của bạn.

Tải file AppImage duy nhất, cấp quyền thực thi và sử dụng ngay trên Ubuntu, Debian, Fedora, Arch Linux:

# 1. Tải bản phát hành mới nhất
wget https://github.com/zalos/zalos/releases/latest/download/Zalos-1.0.0-x86_64.AppImage

# 2. Cấp quyền thực thi
chmod +x Zalos-1.0.0-x86_64.AppImage

# 3. Khởi chạy Zalos
./Zalos-1.0.0-x86_64.AppImage

Dành cho Fedora, Red Hat Enterprise Linux hoặc openSUSE:

# Cài đặt file RPM trực tiếp qua DNF
sudo dnf install https://github.com/zalos/zalos/releases/latest/download/zalos-1.0.0-1.fc40.x86_64.rpm

Cài đặt bản Flatpak an toàn, chạy cách ly sandbox:

# Cài đặt qua file bundle
flatpak install zalos.flatpak

# Hoặc khởi chạy
flatpak run com.github.zalos.Zalos

Khởi chạy tức thì không làm ô nhiễm hệ thống, hoặc tích hợp vào NixOS configuration.nix:

# Chạy trực tiếp qua Flake (không cần cài đặt)
nix run github:zalos/zalos

# Hoặc cài đặt vào user profile
nix profile install github:zalos/zalos

# Hoặc build từ mã nguồn
nix build
./result/bin/zalos

Tự build từ mã nguồn theo chính sách Docker-First (không cài compiler vào máy thật):

git clone https://github.com/zalos/zalos.git
cd zalos

# Build binary Release & chạy kiểm thử CTest
docker compose run --rm build
docker compose run --rm test

# Tạo gói đóng gói AppImage, RPM & NixOS
docker compose run --rm package-appimage
docker compose run --rm package-rpm
docker compose run --rm package-nix
